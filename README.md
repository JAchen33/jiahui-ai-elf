## 🌟 核心特色

- **🧚‍♀️ 溫暖親切的陪伴**：專為班級親師生設計的 AI 對話窗口，傾聽與即時反饋。
- **🌱 彈性身分選擇**：
  - 🎒 **班上小朋友**：查詢作業、問問題、尋求學習建議。
  - 👨‍👩‍👧 **孩子家長**：掌握行事曆、作息與作業規範。
  - 🍎 **教育夥伴**：教學觀摩與交流互動。
  - ✨ **保持神秘（匿名）**：保護隱私，暢所欲言無負擔。
- **⚡ 快速提問捷徑**：
  - 📖 **今日聯絡簿與作業**：即時獲取今日回家作業與攜帶物品。
  - 📅 **近期班級重要行事曆**：重要活動、考試與班級行程不漏接。
  - 📝 **國語 MAPS 提問單指導**：三層次提問技巧與引導小撇步。
  - 🎒 **班級作業與作息規範**：快速了解班級各項常規。
  - 💬 **悄悄話信箱**：安全傳遞想告訴佳慧老師的悄悄話。
- **☁️ 雲端驅動架構**：
  - 前端：現代化自適應響應式介面（Mobile-Friendly、防文字擠壓與換行優化）。
  - 後端：串接 Google Apps Script (GAS) 與 Gemini 大型語言模型，支援上下文對話與後台紀錄。
